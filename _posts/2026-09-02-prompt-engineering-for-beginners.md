# Prompt Engineering for Beginners — The 4-Part Formula That Works

Prompt engineering sounds technical, but it is really just clear communication. The best prompts follow a simple 4-part structure that works across ChatGPT, Claude, and any other AI assistant.

## The 4-Part Prompt Formula

Every high-quality prompt includes:

1. **Role** — "You are a [specific expert]..."
2. **Context** — "Here is the relevant background..."
3. **Task** — "Do [specific thing] with these constraints..."
4. **Output format** — "Return as [table / bullet list / code / email]"

Prompts that skip role + context produce generic results. Prompts that include all four parts produce copy-paste-ready outputs.

## Example 1: Blog Post Outline

> "You are a content strategist. I am writing a post about [TOPIC] for [AUDIENCE]. The goal is [WHAT THEY SHOULD DO AFTER READING]. Generate a H2-level outline with 6-8 sections. For each section, give me: the core insight, one example, and one action step."

## Example 2: Email Draft

> "You are a senior account executive. I need to follow up with a prospect who went silent 7 days ago. Tone: professional, no fluff, direct. Draft a 3-sentence email that asks a specific question and makes it easy to say yes."

## Example 3: Competitive Analysis

> "You are a market research analyst. Compare [COMPANY A] and [COMPANY B] on [DIMENSION]. Output as a table with columns: Feature | A | B | Winner | Why. Keep it scannable."

## Example 4: Code Review

> "You are a senior developer. Review this code for: naming consistency, error handling, performance gaps, and security issues. Return findings as P0/P1/P2 with one-line fixes."

## Example 5: Decision Framework

> "You are a strategy consultant. Here is the decision we need to make: [DECISION]. Here are the options: [OPTIONS]. For each option, list: pros, cons, risks, and a one-line recommendation."

## Common Mistakes

- **No role:** "Write a blog post" → generic output
- **No context:** "Draft an email" → wrong tone
- **No format:** "Analyze this" → unstructured wall of text
- **Too many tasks:** "Do X, Y, and Z" → shallow output on each

## The Fix

Before hitting enter, check: did I include role, context, task, and output format? If not, add the missing piece. The difference in output quality is immediate.
