# Free ChatGPT Prompts for Every Workflow

ChatGPT is powerful, but most people use it like a search engine — type a question, get an answer, move on. The real leverage comes from treating it like a reusable system. Below are the prompt patterns that consistently produce the best outputs across writing, analysis, and decision-making.

## The 4-Part Prompt Formula

Almost every high-quality ChatGPT prompt follows this structure:

1. **Role** — "You are a [specific expert]..."
2. **Context** — "Here is the relevant background..."
3. **Task** — "Do [specific thing] with these constraints..."
4. **Output format** — "Return as [table / bullet list / code / email]"

Prompts that skip role + context produce generic results. Prompts that include all four parts produce copy-paste-ready outputs.

## Writing & Content

**Blog post outline:**
> "I'm writing a post about [TOPIC]. Audience: [WHO]. Goal: [WHAT THEY SHOULD DO AFTER READING]. Generate a H2-level outline with 6-8 sections. For each section, give me: the core insight, one example, and one action step."

**LinkedIn post:**
> "Rewrite this rough idea as a LinkedIn post. Tone: conversational, specific, no fluff. Max 1200 characters. Include a hook in the first line that stops scrollers. End with a question that drives comments."

## Analysis & Decision-Making

**Sprint retrospective:**
> "Here is what my team accomplished last sprint: [LIST]. What did we avoid and why? Output: 1 thing to stop, 1 thing to start, 1 thing to continue. Also flag any risks I missed."

**Competitor comparison:**
> "Compare [COMPANY A] and [COMPANY B] on [DIMENSION]. Output as a table with columns: Feature | A | B | Winner | Why. Keep it scannable."

## Code & Technical

**Debug helper:**
> "Here is my code and the error I'm getting: [PASTE]. Explain the root cause in plain English. Show the fixed code. Then explain why the original failed so I don't repeat it."

**API design review:**
> "Review this API endpoint design for [PURPOSE]. Check for: naming consistency, error handling, rate limiting gaps, auth issues. Return findings as P0/P1/P2 with one-line fixes."
